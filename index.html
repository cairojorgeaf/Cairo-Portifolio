01 / sobre

Sobre

Sou estudante de Sistemas para Internet na UESPI e desenvolvedor full-stack em formação. Gosto de sair do tutorial e construir produtos completos — do layout até a lógica de banco de dados, autenticação e integração de pagamento.

Meu projeto mais recente é o GymFlow, um SaaS de gestão para academias construído com React, TypeScript e Supabase, do zero até o deploy em produção. Também evoluí uma loja virtual para uma aplicação full-stack em PHP/MySQL com pagamento integrado, construí um sistema de autenticação completo e contribuí com a camada de banco de dados de um sistema de agendamento em equipe.

Procuro uma vaga de estágio onde eu possa continuar aprendendo com código de verdade, revisão de outras pessoas e problemas reais de usuário.
